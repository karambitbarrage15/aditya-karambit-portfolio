# Aditya Chaturvedi — Peaches-Inspired Portfolio

An interactive, brutalist web portfolio replicating the exact design language, layout, and fine-art mechanics of [peaches.world](https://peaches.world).

## Highlights & Mechanics
- **Unhidden Renaissance Artworks**: 100% full-vibrancy classical oil paintings:
  - **Chapter 01 (Home)**: Galileo Galilei in the Grand Palace with modern laptop, peach, and astrolabe.
  - **Chapter 02 (Who is talking)**: Aditya Chaturvedi in the Grand Library with modern over-ear headphones.
- **Vertical Right-Hand Raster Switcher (`#wahl`)**:
  - `PIXELS` (Mode 1: Block mosaic)
  - `DOTS` (Mode 2: Halftone dither matrix)
  - `GLYPHS` (Mode 3: Terminal character matrix)
  - `LINES` (Mode 4: Horizontal flowing sine waves)
  - `FULL` (Mode 5: Crystal-clear unhidden fine-art view)
- **3D Mechanical Enter Keycap (`#taste`)**: Tactile depression physics and mechanical audio clack.
- **Top-Right Delete Keycap (`#zurueck`)**: Mechanical backspace return keycap.
- **Beveled Telemetry Badges**: `#kopf`, `#ort`, `#satz` with genuine peaches.world shadows and borders.
- **Warp Perspective Tunnel**: Turbo accelerator tunnel with speedometer leading into the Work exhibition.
